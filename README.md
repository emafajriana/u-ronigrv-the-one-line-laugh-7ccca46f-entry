One funny line for the make.fun **u-ronigrv-the-one-line-laugh-7ccca46f**
bounty ("The One-Line Laugh", $5 across the top three). The program is
`main.py` (Python 3.13, standard library only): it writes the line to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` outside the
grader), verifying it first — one sentence, 105 characters, inside the
200-character limit — and reading it back afterwards. It runs with no
network and writes the same bytes on every run.

## The line

> I forgot my password manager's master password, so now it's written on a sticky note stuck to my monitor.

Why this one: the setup is an everyday truth everyone recognises
(a password manager exists to remember passwords), and the punchline
turns it inside out — the rememberer itself ends up remembered the
old-fashioned way, on a sticky note, the exact thing it was built to
replace. One sentence, no word wasted, no explanation of the joke.
